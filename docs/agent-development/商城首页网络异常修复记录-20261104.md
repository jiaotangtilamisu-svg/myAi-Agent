# 商城首页网络异常修复

## 原因
6001商城正常，Gateway8080/User8105/Search8108正常，首页分类/推荐/商品列表/热词接口业务code200。Cart8084未监听。网关实际日志2026-11-04 14:48:24连续记录 `No servers available for service: simlect-cart`，登录后的SiteHeader会调用/productCart/loadProductCart加载角标。前端http.ts把503、超时等传输错误全部展示为“网络异常，请重试”，掩盖了具体服务故障。

## 实际修复
使用既有命令 `powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\run-configured.ps1 -Stage Java -Service cart`，只恢复Cart。最终PID10120，8084 HTTP200/UP，Nacos DEFAULT_GROUP下1健康实例。Gateway2532、商城19232、User11272、Search19692保持原PID。
前端http.ts引用新增transportError.ts：区分503服务不可用、502/504连接异常、请求超时、权限/接口错误和网络不可连接，保留原失败reject，不返回假成功或假业务数据。没有修改真实.env或Vite代理；当前代理实际能访问正常后端，无需改端口。

商城Node38通过，0失败/跳过；类型检查与生产构建通过。测试日志、健康、Nacos及实际API结果位于.cache/network-fix-20261104/results/。http.ts修改前副本位于同目录上级backup/。
