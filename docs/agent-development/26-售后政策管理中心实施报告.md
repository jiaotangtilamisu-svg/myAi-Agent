## 状态与安全

`DRAFT → submit → PENDING_REVIEW → approve（仍待发布）→ publish → PUBLISHED → disable → DISABLED → enable → PUBLISHED`；reject回草稿，归档进入RETIRED且不可恢复。发布状态与indexState=NOT_INDEXED/INDEXING/READY分离，发布并不代表向量化已经成功。

- publish既要求confirmedPolicy=true，也要求当前版本经服务端审核，来源VALID且处于UTC有效区间；单独传confirmedPolicy不能跳过审核。
- enable要求DISABLED、审核版本一致、审核人存在、来源有效及当前生效；若索引版本未就绪则重排原MQ任务。
- 停用保留原文、版本和向量，权威目录立即拒绝该文档；归档也不物理删除文档或历史。
- 所有管理读写（含原文下载、版本、审核与启停）均复用服务端Redis管理员会话校验；actor从服务端会话生成匿名SHA-256标识，不取请求参数，不存储Token或明文账号。既有会话认证不被替换。
- 分类LAW、INDUSTRY_REFERENCE、PLATFORM_DEMO。法律/行业参考要求发布机构、HTTPS原始网址及发布日期。京东域名来源强制行业参考；默认业务检索排除行业参考。平台规则在界面与Agent回答明确标为演示规则，未审核不能发布。来源真实性仍需人工核实，不把URL格式校验当作真实性认证。
