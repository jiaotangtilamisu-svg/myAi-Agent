# 第23阶段：数据来源及字段映射

来源类型：PUBLIC_DATASET、SYNTHETIC、MANUAL、LIVE_API。未登记业务数据显式UNRECORDED，不自动升级成LIVE_API。技术来源product-service/stock-service与业务数据出处是两个概念。

来源表source_record保留来源名称、原始ID、批次、版本、内容SHA-256、来源URL、许可、UTC入库时间、币种与字段级field_sources。target_service/target_id仅供之后经核实的业务发布绑定；历史客户/订单/支付没有默认业务目标。

## Olist映射

全部文件必须保留原名，目录：E:/Simlect-AI-Mall-main/Simlect-AI-Mall-main/data/olist/raw/。

| CSV | 分析实体 / 主键 | 校验关系及业务限制 |
| --- | --- | --- |
| olist_customers_dataset.csv | customers / customer_id | customer_unique_id保留重复购买关联；不转user_info，不转当前登录身份 |
| olist_sellers_dataset.csv | sellers / seller_id | 仅历史卖家分析，不建立正式商家账号 |
| olist_products_dataset.csv | products / product_id | 保留category和物理属性；无真实标题/SKU/库存，不直接发布 |
| olist_orders_dataset.csv | orders / order_id | customer_id→customers；原始状态和时间保留，绝不写业务order_info |
| olist_order_items_dataset.csv | order_items / order_id+order_item_id | 订单/商品/卖家逻辑外键；price、freight_value为原BRL小数 |
| olist_order_payments_dataset.csv | order_payments / order_id+payment_sequential | payment_value为历史BRL；只分析，绝不调用支付服务 |
| olist_order_reviews_dataset.csv | order_reviews / 规范化完整行SHA | review_id不假设全局唯一；不同记录保留，相同记录去重；order_id外键 |
| olist_geolocation_dataset.csv | geolocation / 规范化完整行SHA | 邮编前缀可多行，不假设唯一；前导0保留，经纬度范围校验 |
| product_category_name_translation.csv | category_translation / product_category_name | 原文与英文保留；不能把翻译当作具体商品名称 |

金额用Decimal、最多两位小数，空值保持null，不变为0。币种BRL不自动换算CNY。源时间保持原字符串，来源时区UNSPECIFIED，不伪装UTC。入库observed_at为UTC，二者独立。

表头缺失/重复、金额非法、主键冲突、孤儿引用阻止导入；完全相同记录去重并计数。历史“送达早于下单”作为质量警告保留，不替历史数据造正确时间。空商品分类保留未知，不编造类别。

## 合成候选目录映射

15款、5类，每款2个SKU。名称/分类为本项目手工维护无品牌资料，fieldSources为MANUAL；SKU、99/149元价格及30/0库存全部SYNTHETIC。币种CNY，没有引用Olist历史金额。

来源project://tools/data_governance/catalogue.py，版本synthetic-catalogue-v1；名称强制[合成测试]前缀。ProductSaveDTO适配器生成productInfo/productPropertyList/skuList，默认下架status=0，不指定服务器生成的productId。库存不重新写回product_sku.stock，后续应经Stock接口并登记目标绑定。

MCP/Python商品事实可保留data_provenance，卡片投影转dataProvenance；前端显示“公开历史数据·非当前交易”“合成测试数据”“手工维护资料·含合成字段”或“业务来源未登记”。PUBLIC_DATASET商品禁止作为当前现货推荐。原价格/库存未知规则保持。
