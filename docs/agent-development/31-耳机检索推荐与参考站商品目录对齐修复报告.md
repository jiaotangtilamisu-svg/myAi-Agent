## 已确认根因

1. 搜索对分词结果使用OR，耳机图案手机壳也被当作耳机；中文分词还可能把“手机壳”拆为单字，误命中伴手礼。
2. 消息71继承消息70的100元预算；消息75继承消息74的100元下限。因此89.90元与129.90元两款被不同旧条件分别排除。
3. 原推荐没有解析目标数量，也没有说明不足三款。
4. 旧ABO目录与参考站商品不是同一目录，不能通过修改图片标签达到一致。
